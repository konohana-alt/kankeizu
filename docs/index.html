テキストで書ける、
動く人物相関図

JSON（DSL）で物語の構造を記述するだけで、人物の関係変化がステップごとにアニメーションで再生される。スライドのように進み、注目すべきノードへカメラがズームインする。DSL の生成は AI に任せられる。

DSL（JSON）の例 → エンジンが自動でアニメーション再生
"nodes": [ { "id": "alice", "label": "アリス", "icon": "farmer" }, { "id": "bob", "label": "ボブ", "icon": "knight" } ], "edges": [ { "from": "alice", "to": "bob", "history": [ { "step": 0, "label": "他人" }, { "step": 3, "label": "同志", "color": "blue", "weight": "thick" } ] } ]

このJSONをエンジンに渡すだけ。あとは自動で動く。

なぜ作ったか 背景

きっかけは、人間関係が変わっていく放置ゲームを作りたい、という発想だった。 複数人のキャラクターが時間とともに関係を変え、プレイヤーはその変化を眺めて楽しむ。 そういうゲームを作るとき、プレイヤーが直感的に状況を理解できる画面が必要になった。

思い浮かんだのは、ドラマの公式サイトによくある人物相関図だった。 あれを動かせたら面白い。関係が変化するたびに線の種類や色が変わり、 人物がグループを移動していく。静止画ではなく、物語の流れそのものが見える図。

時系列で作ると、人物相関図が動いてドラマチックになる。これは便利だと気づいた。

そしてもうひとつの発見があった。DSL（JSON）を書く過程で、 物語の矛盾や曖昧さが自然と潰れていくということだ。 「この人物はそのステップでどこにいたのか」「この2人の関係はいつ変わったのか」 ——そういった問いに構造として答えなければ DSL は書けない。 整理し終えた時、それが自然と相関図の形になっている。

さらに、DSL はテキストなので AI が編集できる。 Claude や Gemini にストーリーを渡せば、人物・関係・変化のすべてを DSL として書き出してくれる。 人間は座標の微調整と画像の差し替えだけをすればいい。 ゲーム制作のために作ったツールが、物語を持つあらゆる場面で使えるものになった。

できること Features

🎬

時系列アニメーション

ステップごとに関係線・グループ・アイコンが変化。物語の流れが一目でわかる。

🎥

カメラワーク

スライドのように1ステップずつ進み、注目すべきノードへ自動でズームイン・アウト。プレゼンテーションのような演出ができる。

🤖

AI で全部書ける

DSL は JSON なので Claude・Gemini 等に生成させられる。MCP サーバーで検証も自動化。

✏️

位置を手で直せる

編集モードでノードをドラッグして微調整。画像の差し替えもブラウザ上で完結。

📤

1ファイルで公開

「公開」ボタンで編集機能を除いた閲覧専用 HTML を生成。そのまま配布できる。

📦

外部依存なし

エンジンは HTML 1ファイルで完結。サーバー不要、インストール不要。

🗺️

背景マップ対応

地図や見取り図を背景に敷いて、場所と人物の動きを重ねて表現できる。

可能性 What it could become

「人・もの・こと」に位置と時刻さえあれば、何でも表現できる。

⚽

スポーツの戦況

サッカーなら22人の選手とボール。時系列の位置データがあれば、試合の流れをそのまま相関図として書き出せる可能性がある。

🌍

歴史の同時観察

歴史の教科書を読み込ませたら、大陸ごとの出来事を同じ時間軸に並べて同時に観察できるかもしれない。

🎮

ゲームの人間関係

放置ゲーム・RPG・シミュレーション。キャラクターの関係変化をプレイヤーに見せるインターフェースとして。

📖

小説・脚本の構造化

誰がいつどこにいたか、関係がいつ変わったか。書きながらプロットの矛盾が自然と潰れていく。

🏢

組織・プロジェクト

チームの編成変化、人員の異動、プロジェクトの関係者の増減を時系列で記録・共有する。

🔭

まだ見えていない用途

「人・もの・こと」の関係が時間で変わるものなら、たぶん何でも。あなたのアイデアを聞かせてほしい。

使い方 Quick Start

1

デモを見る

bastille_demo.html をダウンロードしてブラウザで開く。バスティーユ襲撃（フランス革命・1789年）の人物相関がアニメーションで動く。

2

エンジンに自分のDSLを読み込む

kankeizu_engine.html を開き、「脚本を編集」パネルに JSON を貼り付ける。

3

AI に DSL を書かせる — Remote MCP（インストール不要）

Claude Desktop / Claude Code の設定に以下を追加するだけで、validate_dsl など全ツールが使える。Node.js・インストール不要。

{
  "mcpServers": {
    "kankeizu-dsl": {
      "url": "https://nwkjo52kv6.execute-api.ap-northeast-1.amazonaws.com/prod/"
    }
  }
}
4

AI に DSL を書かせる — ローカル MCP（Node.js がある場合）

mcp/ フォルダをダウンロードして npm install。agent-prompt.md の手順に沿って Claude や Gemini に DSL を生成させる。

5

公開する

✏️ 編集モードで位置を微調整し、📤 公開ボタンで閲覧専用 HTML を生成して配布する。

一緒に盛り上げてほしいです。
